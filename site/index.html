Start on Windows

三步，把猴子请进电脑。

当前提供 Python 项目源代码的可运行候选版，而不是已经通过 Windows 兼容性验收的安装包。

获取并解压完整工程

保留所有文件，包括 assets、site、core 和 ui 文件夹。

首次执行 setup_windows.bat

需要在 Windows 10/11 上预先安装 Python 3.12；安装脚本会安装 PySide6 等运行依赖。

双击 run_windows.bat

猴子出现在桌面。右键角色或托盘图标 →「🐒 猴子数量」，直接选择 1～6 只；也可投喂、专注和退出。

⚠ 候选版提示：我们仍需验证 Windows 的透明区域点击穿透、DPI、多显示器、焦点与长时间稳定性。若运行遇到问题，请先退出桌宠，别将代码候选误认为正式稳定版。

Quick answers

经常被问到的事。

这些猴子真的能在 Windows 上运行吗？

源码和自动化逻辑测试已提供；但开发容器不是 Windows，因此透明窗口点击穿透、系统托盘和 EXE 打包效果仍需要真实 Win10/11 电脑进行验收。

会不会看我的电脑正在做什么？

不会。没有全局键盘内容采集、录屏、浏览器页面分析和联网遥测；追鼠标使用桌面指针位置，不读取其文字内容。专注计时也不观察你的工作。

猴学勋章和日记记录在哪里？

勋章默认关闭，开启后只把猴子交互次数写到本地应用目录的 progress.json；旧版事件收藏独立开关。所有数据都可以从程序内清除或手动删除本机配置目录。

多只猴子之间真的会互动吗？

可以从「猴山管理局」设置名字和性格。v0.8 增加了猴子关系记忆、每日任务、可拖动家具与故事卡；v0.7 已加入轻量横向碰撞、自由/跟随行动，以及公共香蕉竞速：地面附近的角色相遇会分开并弹开；也可以让猴助教跟随教授，或放置公共香蕉让猴子按性格速度竞速。碰撞不是完整刚体物理；联合会议仍是编排短剧。网页按钮只是离线演示，不能控制应用；Windows 真机兼容性仍待验证。
