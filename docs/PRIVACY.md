# ProfMonkey Desktop — 隐私说明（v0.6 源码候选版）

本程序默认完全离线。源码目前不调用浏览器历史、剪贴板、密码、录屏、麦克风或网络上传接口，也没有全局键盘钩子。观察鼠标的实现仅使用当前鼠标的**坐标**，用于让自己的猴子朝向或追逐光标；**不改变真实光标的位置**。

仅在用户主动点击/拖动本软件窗口时响应交互。`input_tracking` 保留为兼容字段，但强制关闭，**本候选版未实现后台键盘活动统计**。键盘暴走短剧需要从托盘/右键菜单手动触发，不能宣称它读到了用户打字节奏。

## 本地保存什么

- 默认保存用户主动修改的设置：模式、大小、频率、配色、音效等。路径：Windows `%LOCALAPPDATA%\ProfMonkeyDesktop\settings.json`。
- “事件收藏”**默认关闭**。主动勾选后，在相同文件夹 `events.json` 中只保存事件代号和结束时间（保留最新 100 条）。菜单中可以清空。
- **猴学勋章默认关闭**。用户自愿在设置里开启后，`progress.json` 只保存本软件内部互动计数（点击/投喂/抛掷/故事/专注时长），不包含时间点、应用名称、键盘文字、窗口标题。菜单「🏅 猴学档案」可以彻底清除这份本地文件。关闭开关会停止写入，但不会自动删去原文件；需要手动使用「清除本地勋章数据」。
- **多猴名字、性格、数量及是否允许自动联合短剧**保存在同一个 `settings.json`，默认没有自动联合短剧；编辑的名字只有在本地合照时会被画到图片中。
- **自定义语录**存在 `settings.json`，不传输、不执行文本；可在设置里删除内容后保存。
- **本地专注计时**仅在运行进程的内存中倒计时；专注完成后仅在用户启用勋章时累计完成次数/分钟，不追踪用户正在操作的程序。
- 猴山合照 PNG 导出只使用本项目自带的猴子动作素材及用户自行输入的名字，不读取桌面；只有用户选择保存位置后才会生成文件。
- GIF 导出只使用项目自身的图片素材与故事台词渲染；不会截取桌面、任何窗口或私人文件。用户通过文件选择框指定保存位置。
- 不创建开机自启项，不主动添加快捷键监听或管理其他窗口；不会删除、编辑用户其他文件。

## 有关桌面显示

无边框透明窗体 + PNG Alpha 遮罩用于尽量使透明区域点击穿透；Windows 10/11、缩放和焦点行为需要实际验证，代码测试不能替代真机验收。右键猴子和系统托盘都提供退出菜单。

第三方 Python 依赖（PySide6 / Pillow）以及 Windows 系统本身受其各自许可、系统策略影响。这份说明只描述我们的应用行为，不对整个设备所有软件做保证。
