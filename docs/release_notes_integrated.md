# ProfMonkey Desktop v0.3.0-integrated-candidate

日期：2026-10-25 | 类型：开发者候选构建（非正式 Release）

以 P02 原型为基础新增：屏幕安全移动 / 简单投掷物理、自主行动与数值状态、13 种动作、完整香蕉双结局、教授黑板互动、镜像和键盘暴走视觉短剧、轻音效、安静/猴山、可选历史收藏、尺寸和皮肤配色、可分享原创 GIF。本包提供完整代码与 Windows 双击脚本，但**不包含已验证 Windows EXE**。

自动测试验证范围：纯 Python 动作、状态、运动、剧情、配置、GIF 路径；图形相关测试需安装 PySide6，在真实 Windows 上观察焦点/遮罩。

已知限制：

- 最关键的 P01 点击穿透 + 拖拽并存尚未 Windows 验收。
- 未实现全局输入频率检测（避免敏感采集）；键盘暴走只能手动播放。
- “分身”是视觉效果，不是真正的多个独立宠物进程或独立窗口。
- 未实现任意应用窗口攀爬、完善的多屏生命周期、自定义语言包和完整换装。
- 没有对外发布数据、小时级长稳报告或 SmartScreen 测试记录。
