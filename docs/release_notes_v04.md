# ProfMonkey Desktop v0.4 — 好玩也能陪你学习（源码候选版）

日期：2026-10-25。**代码候选，不是 Windows 正式 Release。** 基于 v0.3 整合工程继续增量开发，没有删除原有故事、动画、配色或导出功能。

## 新功能（代码实现）

- **🍌 主动投喂**：在猴子或托盘菜单中喂香蕉，精力 +12、心情 +9，角色进入吃香蕉动画，不需要自动故事。
- **📚 安静专注时钟**：15/25/45/60 分钟，独立时钟可暂停、恢复、终止。专注中禁止自动散步/意外故事，结束后在桌宠气泡庆祝。计时只在软件运行时有效，不读取用户电脑正在做什么。
- **🏅 猴学档案**：7 种勋章；只统计用户自愿开启后和**本软件**的点击、投喂、投掷、故事完成、专注时长。默认关闭、可清除，不收集输入文本，也不联网。`progress.json` 与历史收藏 `events.json` 完全分离。
- **💬 自定义语录**：设置里每行一句，上限 12 句，每句至多 44 个可显示字符；随机展示。没有联网大模型、不会执行用户文本。
- **🏠 回家 + 随机整活**：从托盘菜单复位位置、触发随机短剧。
- **🌐 全新介绍页面**：`site/index.html` 为自包含离线响应式网站（静态 HTML + 本地图片素材），可在应用菜单的「关于 ProfMonkey · 介绍页面」打开。包含交互式猴子演示、故事 GIF、动画图、隐私、安装、FAQ 和明确的发布状态。

## 文件变化

`core/focus.py`、`core/progress.py`、`ui/dashboard.py`、`site/`、`tests/test_personality_focus.py` 为新增；`app.py`、`core/config.py`、`ui/overlay.py`、`ui/tray.py`、`ui/settings_dialog.py` 和 Windows 打包脚本为扩展。

## 当前限制与风险

- **Windows 透明点击穿透与焦点行为未实测，P01 门禁仍未正式关闭。**
- 用户自行在 Win10/Win11 运行并确认托盘/菜单/窗口生命周期和全屏场景后，才可考虑正式发布。
- 网站内的桌宠按钮是浏览器交互演示，不能控制本地桌宠进程；页面中显示的数字是项目代码与素材数量，不是市场或兼容性统计。
- 番茄钟不在进程退出后继续计时；无后台任务、无联网服务，也不跟踪鼠标点击其他应用的行为。
- 勋章保存默认关闭；如果用户关闭后重新打开，旧文件中之前主动保存的进度会继续保留，需通过「清除本地勋章数据」主动擦除。
