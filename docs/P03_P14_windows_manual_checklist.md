# 整合候选版 Windows 真机测试表

系统版本：_____  DPI：_____  多屏：_____  开始时间：_____  执行人：_____

## P01 / P02（阻断项）
- [ ] 启动没有黑底或黑色矩形；角色可见、帧动画稳定。
- [ ] 角色外透明区可以正常点到浏览器、VS Code、桌面图标。
- [ ] 点击角色本体不会穿透到下面的软件。
- [ ] 普通状态不抢焦点，输入代码时不会闪烁或丢字。
- [ ] 托盘和角色右键都能暂停、退出（无任务残留）。

## P03—P07（核心闭环）
- [ ] 猴子走动不出屏幕，碰到边界会返回。
- [ ] 快速拖拽松手后符合预期抛物线并落地，无永久卡住。
- [ ] 菜单香蕉事故完整自动结束；香蕉皮和甩锅牌子被清除。
- [ ] 出现香蕉皮时点击，能够阻止事故（多次尝试）。
- [ ] 更换窗口大小、置顶、行为频率后重启设置仍有效。
- [ ] 猴山和安静切换、暂停/继续能立即阻止不应发生的动作。
- [ ] 常见软件（IDE、浏览器、会议、全屏游戏）正常使用。

## P08—P12（部分功能）
- [ ] 鼠标追逐和逃跑仅产生猴子自身移动，系统鼠标没被挪走。
- [ ] “键盘暴走”确认为**手动**，无后台按键监听。
- [ ] 黑板、镜像、坠落短剧没有悬浮残留。
- [ ] 配色切换无崩溃；音效默认关闭，打开后足够轻。
- [ ] 动作 GIF 和剧情 GIF 可由系统图片查看器播放，均无桌面隐私。
- [ ] 历史收藏默认关；主动打开后有记录；清空后文件不存在。

## P13 / P14（发布门禁）
- [ ] 100%、125%、150%、200% DPI 逐一测，没有丢猴。
- [ ] 两屏之间拖动、分辨率改变、插拔显示器、睡眠唤醒无卡死。
- [ ] 连续 2 小时正常运行，CPU 空闲 / 内存稳定且无系统输入问题。
- [ ] 三位非开发者独立安装、触发一次香蕉事故并正常退出。
- [ ] `build_windows.bat` 生成 EXE 在未安装 Python 的干净 Windows 设备可运行。
- [ ] Windows Defender/SmartScreen 行为已记录；README、许可证、隐私声明一致。
