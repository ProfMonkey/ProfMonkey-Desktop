# 🐒 ProfMonkey Desktop v0.14 — 猴山自治（源码候选）

## 核心：议会通过的规定，终于能改变后续猴山生活

沿用 v0.13 的三至六猴、三幕投票流程。**只有完整播放最后一幕，才会自动写入新的本地「猴山法令」**；被打断的投票、预览票型不会生效。过半通过→规定生效，过半反对→废止已有规定，僵持→现状不变。

三个纯虚构政策与真正的游戏后果：

- **🍌 香蕉共享条例**：公共香蕉竞速照常进行。获胜猴子获得香蕉，其余猴子得到香蕉片、心情 +2，与赢家之间记为合作而不是竞速竞争。条例没通过时继续采用原来的赢家独享竞速规则。
- **🌙 猴山安静公约**：停掉**自动触发**的双猴碰面和猴山群体短剧（无论现实世界钟点）；**不影响**用户手动触发的剧情、通知、声音开关、操作系统和真实电脑静音。
- **🚀 火箭试飞许可**：解锁「猴山自治 → 开始已批准的猴山试飞」，至少 3 只猴子在场、必须包含发明猴。试飞为原创三幕剧情：点火许可→发射事故→安全落地。发明猴担任主演、队长猴（若在场）负责监督；如果手动中断则不记入猴山纪事。若已启用 v0.12 虚构连续剧情，完整试飞后可开启火箭线索案。

## 法令管理

右键猴子 / 托盘 → **📜 猴山自治 · 法令与火箭试飞**。可查看三条政策及其效果、最近 24 条虚构议会结果，按钮手动试飞或**明确确认后清空猴山法令**。重置不会删除猴际关系、成长、猴山纪事和其他用户设置。

`core/governance.py` 实现白名单 JSON、字段类型验证、原子替换、最多24条议会记录；本地单文件 `monkey_laws.json` 独立保存。未召开有效完整议会时**默认不会创建法令文件**。不联网、不扫描真实文件、不读取用户输入、窗口标题或键鼠内容。

`site/governance.html` 是独立、离线、只存于当前浏览器页面内存的投票/法令/行为演示。这里的模拟按钮不接入桌宠存档。
