# P07 多猴物理互动 Windows 手工验收

请在 Windows 10/11 上按顺序检查；未实测项目不要标记通过。

- [ ] 选择 2 只猴子，点击「放置公共香蕉」：香蕉显示在桌面可见区域。
- [ ] 两只猴子朝香蕉移动，速度倾向与性格相符；先到者吃香蕉，另一只显示失落台词。
- [ ] 点击香蕉可以中止竞速，猴子恢复自主行为。
- [ ] 竞速期间暂停所有猴子，目标移动停止；恢复后能继续。
- [ ] 开始专注后无法启动竞速；专注结束后菜单功能恢复。
- [ ] 切换「跟随猴教授」，其余猴子在地面附近尝试排队跟随，不永久离开屏幕。
- [ ] 切换「自由生活」，跟随目标被清除，猴子恢复各自自主行为。
- [ ] 开启碰撞，令两只猴子在地面附近相遇：角色分开、出现短促反弹/吐槽，不闪烁、不无限抖动。
- [ ] 关闭碰撞后相遇不会触发新的碰撞反应。
- [ ] 拖拽一只猴子穿过另一只：被拖动的角色不会被物理引擎反复拉走；松手后能恢复。
- [ ] 触发联合短剧时，碰撞与跟随不会打断短剧；短剧结束后恢复群体行动。
- [ ] 1→2→6→1 只调整数量后，没有残留香蕉窗口、定时器或幽灵猴子。
- [ ] 在 100% / 125% / 150% 缩放下检查香蕉图标点击区域、角色点击穿透和焦点。
- [ ] 连续运行 30 分钟，观察 CPU、内存、动作抖动和退出后的残留进程。

## 回归红线

任何情况下均须保留：一键暂停、隐藏和退出；不读取键盘文本/剪贴板；不移动真实鼠标；不截取桌面；透明区域不遮挡其他窗口的操作。
