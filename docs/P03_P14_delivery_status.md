## 为什么仍不能宣布 v1.0

P01/02 的真实 Windows 图形行为没有现场运行记录，故不满足最初计划要求的“每阶段必须验收再进入下一阶段”。这次按用户要求先**并行把后续功能代码整合出来**，但保留未完成的质量门禁，不能将代码存在等同于功能稳定。

## 最优先核查顺序（本机）

1. 解压双击 `setup_windows.bat` 和 `run_windows.bat`；检查猴子本体、遮罩外是否正常操作桌面。
2. 戳猴子、拖起/抛开、切换安静与猴山、暂停、菜单退出。
3. 菜单依次试五种短剧（香蕉、黑板、镜子、键盘、坠落），特别测试“点击香蕉皮取消事故”。
4. 改大小为 90 / 160 / 240，分别在 100%、125%、150% Windows 缩放下测试；跨显示器/远程桌面/休眠唤醒复测。
5. 开关声音、保存设置、退出重开、导出 GIF、打开收藏/清空。
6. 运行 `test_windows.bat`；连续保持运行至少两小时，关注焦点、CPU 和内存、睡眠恢复。

## 安全与回退

- `main` 仍保留最早 P01 稳定代码；整合候选放在独立 Git 分支 `feature/integrated-v03`。
- 功能出错时可以右键退出 / 系统托盘退出；若窗口或托盘都失效，可从任务管理器结束 `python.exe` 或 `ProfMonkeyDesktop.exe`。
- 不建议在本候选版上启用开机自启动（代码也没有提供）。
