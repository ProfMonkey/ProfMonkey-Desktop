# P08 猴山生活系统 · Windows 手工验收表

在真实 Windows 10/11 上运行前，先安装依赖并启动 `run_windows.bat`。每项都需要实际点击确认；纯逻辑测试不能替代 GUI 验收。

## 关系档案

- [ ] 右键猴子/托盘打开「猴山关系档案」。
- [ ] 两只猴子开完完整会议后，好感与信任增加。
- [ ] 完整香蕉争夺战后，竞争值增加；中途取消不会加关系值。
- [ ] 多次连续碰撞不会每帧刷关系，关系值仍被限制在有效范围。
- [ ] 「安排和解」会降低竞争、提高好感与信任。
- [ ] 「设为师徒」保存后，关闭并重新打开关系档案仍显示。

## 家具与道具

- [ ] 右键/托盘 →「猴山家具与道具」分别放置香蕉树、黑板、蹦床、教授椅和镜子。
- [ ] 左键点击触发对应互动；拖动时不会误触发。
- [ ] 右键家具可收起；「收起所有家具」可清理所有道具。
- [ ] 暂停或专注时，家具不会启动剧情或强制移动猴子。
- [ ] 最多可摆放 8 件；超过上限有提示。
- [ ] 隐藏所有猴子后家具也隐藏；再次显示时可以恢复。
- [ ] 退出应用后没有残留家具窗口。

## 每日任务与故事卡

- [ ] 今日任务日期与本地日期一致，三项任务轮换正确。
- [ ] 投喂、手动短剧、完整会议/香蕉竞速能按任务要求更新进度。
- [ ] 只有完成全部当日任务才发放 3 点奖励；重复触发不重复领奖。
- [ ] 重启后积分与当天进度仍保留；日期变化后任务重置、累计积分保留。
- [ ] 故事卡导出为 1200×800 PNG，文字与猴子素材可见。
- [ ] 导出的故事卡不包含桌面截图、其他应用内容或真实鼠标。

## 回归与安全

- [ ] 透明区域穿透、角色拖拽和托盘退出仍正常。
- [ ] 全局暂停/隐藏/退出能覆盖所有猴子和家具。
- [ ] 专注期间不启动自动短剧。
- [ ] 检查应用配置目录中的 `relationships.json` 和 `daily_quests.json`，确认无键盘文本或窗口标题。
- [ ] 连续运行 60 分钟无明显 CPU/内存异常或崩溃。
