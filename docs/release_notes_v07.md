# ProfMonkey Desktop v0.7 — 物理互动候选版

## 新增

- **轻量横向身体接触**：同屏、接近地面的猴子发生可见角色边界重叠时，会被分开并在相向运动时弹开；短暂显示碰撞吐槽。碰撞是卡通式横向接触模型，不是完整刚体模拟。
- **群体行动方式**：在托盘/角色右键菜单「🐾 猴山行动与物理互动」中切换「自由生活」和「跟随猴教授」。选择会写入本地设置。
- **公共香蕉竞速**：至少两只猴子时，可在桌面生成一枚程序自身绘制的透明香蕉道具。猴子会按性格速度冲向香蕉；先到者获得投喂奖励，其他猴子会吐槽。点击香蕉可取消争夺。
- **碰撞开关**：可在菜单关闭/开启软碰撞；设置本地保存。
- **介绍页更新**：添加碰撞、跟随模式与公共香蕉竞速的介绍，并在浏览器内提供独立模拟按钮。网页演示不会操控桌宠。

## 安全和边界

- 不新增全局键盘监听、屏幕录制、网络遥测或其他窗口控制。
- 香蕉道具只在软件自身透明窗口内绘制，不截图桌面。
- 公共香蕉竞速需要至少两只猴子；专注、暂停或其他短剧进行时不会启动。
- 群体物理是轻量横向接触处理；不模拟完整的垂直刚体、骨骼或环境碰撞。

## 自动化验证

- 新增纯 Python 碰撞分离、弹开、垂直隔离、边界夹取、设置持久化测试。
- Qt/Windows 实际窗口测试需要安装 PySide6，并在 Windows 10/11 真机检查透明穿透、多个窗口的 Z 顺序、碰撞视觉效果和长稳表现。
- 本开发容器没有 PySide6/Windows 桌面，因此本版本仍是源码候选版，不宣称 Windows GUI 已验收。

## 操作

1. 右键猴子或系统托盘。
2. 打开「🐾 猴山行动与物理互动」。
3. 选择「自由生活」或「跟随猴教授」，按需开启/关闭身体碰撞。
4. 选择「放置公共香蕉 · 猴子竞速」。需要至少两只猴子。点击香蕉道具可取消本次争夺。
