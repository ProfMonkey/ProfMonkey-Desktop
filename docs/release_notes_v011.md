# 🐒 ProfMonkey Desktop v0.11 — 猴山化学反应（源码候选）

> ⚠️ 本分支基于 GitHub main 的 **v0.9 文本源码**，不是把未上传的 v0.10 396 帧像素素材恢复到了 GitHub。仓库根目录缺少运行所需的二进制 PNG/WAV；早期二进制素材位于仓库内 v0.9 分片源码档案。请勿将此分支称为可运行的 v0.10 完整包或 Windows 发布版。

## 这次确实写进代码的内容

- 六种性格选项：学究猴、皮猴、困猴、发明猴、队长猴、社恐猴。旧的前三种值完全兼容。新三种有各自的 **Brain 权重** 与公共香蕉移动速度（不只是改一段台词）。
- 关系优先的 7 个组合事件：学究×发明（学术审查）、队长×皮猴（纪律检查）、队长×困猴（晨间点名）、皮猴×社恐（尊重边界）、学究×社恐（安静阅读）、发明×困猴（睡眠仪）、队长×发明（试飞审批）。
- 原有关系规则仍然优先：高竞争值→争论；高好感+信任→击掌；普通性格组合仍可睡觉、恶作剧和打招呼。
- 原有单幕碰面升级为 **两幕事件**：开头发生—第二幕收尾。角色按身份获得专属台词，避免把队长的台词错发给困猴。
- **只有第二幕正常播完才修改关系**；拖拽、暂停、专注、隐藏、关闭自动碰面、减少猴子数量都可以中断，不会记录没发生完的剧情。自动碰面仍默认关闭、只在猴山模式工作，延续 120/240 秒冷却。
- 合照/故事卡不会因为新增的三种性格崩溃；如果新像素素材不存在，会使用已有本地动作图作为保守回退。**这不表示新三种角色外观已完成！**
- 新增无界面的回归测试与独立介绍页「猴山化学反应演示」，均离线且不访问桌面内容。

## 开发者验收

核心快速测试（无需 Qt/Pillow/素材）：

```bash
python -m pip install pytest
python -m pytest -q tests/test_v09_encounters.py tests/test_v011_personality_chemistry.py
```

全量测试必须在获取完整素材和依赖后执行：

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Windows 现场核验步骤见 [P11_windows_checklist.md](P11_windows_checklist.md)。
