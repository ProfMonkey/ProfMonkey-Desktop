# v0.4 新功能选择说明（2026-10-25）

本轮按「有趣、愿意常开、不干扰、不联网也能用」筛选。在现有桌宠产品和开源案例中，**专注辅助、投喂、成就、个性化语录、角色状态**都较常见。本次不复制任何项目的代码或素材，只把适合 ProfMonkey 的交互写进现有架构。

| 功能候选 | 本轮决策 | 原因 |
| --- | --- | --- |
| 主动香蕉投喂 | **已加入** | 把猴子状态与用户互动形成闭环，开发量小、可用性高 |
| 专注陪伴时钟 | **已加入** | 让桌宠长期存在有一个实际理由；纯本地计时 |
| 猴学勋章与档案 | **已加入，默认关闭** | 给持续使用提供反馈，但不偷偷记录活动 |
| 自定义猴学语录 | **已加入** | 低门槛生成可分享梗，清晰区别于 AI 聊天 |
| 教授猴介绍页 | **已加入** | 易于展示、转发演示与 GitHub README，所有素材本地 |
| 一键归位、随机短剧 | **已加入** | 可发现性、找回性、降低菜单层级 |
| 真正多猴独立物理实体 | 延期 | 需要重构场景实体、遮罩区域与碰撞管理 |
| 真实窗口攀爬 | 延期 | Windows 窗口 API + DPI/焦点问题，P01 未验收 |
| 输入统计、屏幕感知、AI 聊天 | 不在本次范围 | 需要权限/联网/明确授权，不应在展示功能之前引入 |
| 联网社交、全球排行榜 | 延期 | 需要服务端、账号、隐私设计；目前先验证桌宠是否值得常开 |

**验收边界**：完成源码与自动测试，不等于运行稳定。Windows 的透明遮罩、托盘、焦点与 DPI 仍需实机检查。
