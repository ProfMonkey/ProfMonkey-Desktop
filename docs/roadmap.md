# ProfMonkey Desktop — 开发路线图

## 当前版本

**v0.8 猴山生活系统候选版**。当前开发分支：`feature/v08-colony-life-system`。核心逻辑与资源可以在非 Windows 环境测试；PySide6 GUI、透明窗口点击穿透、系统托盘、家具窗口和 Windows 打包仍需在真实 Windows 10/11 电脑验收。

## v0.8 功能范围

1. `core/relationships.py`：本地关系记忆、好感/竞争/信任、师徒关系、和解操作。
2. `core/quests.py`：按本地日期轮换每日任务，任务积分和完成记录。
3. `ui/furniture.py`：可拖动、可点击、可右键收起的桌面道具窗口。
4. `ui/relationship_dialog.py`：查看关系并安排和解/师徒。
5. `ui/quest_dialog.py`：查看今日任务进度和积分。
6. `core/story_card.py`：从本地猴子素材与文案生成可分享 PNG，不录制桌面。
7. `site/index.html`：新增关系、家具、每日任务、故事卡的纯网页模拟演示。

## 下一步优先级

- **P13：家具环境感知**：猴子走近家具时触发动作，加入每件道具冷却和用户可关闭的自动互动。
- **P14：连续剧情引擎**：根据关系、道具和历史事件选择分支，提供可复现的剧情记录和回放。
- **P15：Windows 发布门禁**：透明区点击穿透、角色拖拽、焦点、多屏/DPI、休眠唤醒、CPU/内存、长稳、打包与卸载。

## 不可妥协的底线

1. 不读取键盘文本、密码、剪贴板、浏览内容；不做未经授权的录屏或上传。
2. 不移动真实鼠标、不修改桌面图标、不操纵其他应用窗口。
3. 永远提供暂停、隐藏和退出入口；专注时不自动整活。
4. 不把源码编写完成等同于 Windows 真机验收通过。
