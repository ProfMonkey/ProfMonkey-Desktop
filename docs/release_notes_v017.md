## 从四座建筑到四份有记忆的故事

当 v0.16 四座建筑真正建好后，可以解锁四个案件，每个案件都有三章，每章三幕，合计 **12个可持久推进的章节/36段场景**。

| 必须实际建成 | 故事 | 三章 |
|---|---|---|
| 🍌 香蕉研究仓库 | 午夜香蕉失窃案 | 空空的仓库 → 失踪的收据 → 猴山公开听证 |
| 🔭 银河猴山望远镜 | 来自银河深处的信号 | 会眨眼的星星 → 反向观测 → 第一张星图 |
| 🏛️ 猴山公共广场 | 猴山广场庆典 | 庆典准备日 → 彩排事故 → 共同的舞台 |
| 🌌 银河猴山联合实验室 | 联合实验室事故 | 烟雾报警 → 失控的机器 → 新的实验室章程 |

用户可以从**右键/托盘 → 🗞️ 活着的猴山**选择案件、两只猴子和当前章节的解决方案。点击桌面上已建成的建筑，也可以直接进入对应案卷。未建造的建筑不能靠直接调接口启动相应故事。

## 选择改变后续世界

同一章可选：

- **谨慎调查：** 强调证据、安全与协作；两只猴子的好感、信任提高。由于谨慎，也可能消耗少量虚构香蕉或科研点。
- **大胆冒险：** 可能迅速收获虚构香蕉、科研点或者声望，但也会增加争议和猴际竞争。

不同角色台词不再完全一样，学究、皮猴、困猴、发明猴、队长和社恐猴都有选择对应的自有反应。

每个案件第三章根据**之前累计谨慎/大胆选择**以及**两只角色已经保存的好感与信任**走向「达成共识」或「留下争议」。这不是外部随机情节生成，而是可检验的确定性多分支故事。

## 真正实施的游戏后果

每章是带有计时的有限三幕。仅当所有场景正常结束才允许消费一次完成标记，才能：

1. 将这一章视为完成，保存选项与最终结局。
2. 按本案与选择扣除或奖励少量**游戏内**香蕉、科研点、声望，资源限制在0～999。
3. 对两只参演猴子写入合作或争论的关系变化；结案时还有额外和解或争论后果。
4. 将城市事件写入已有离线的猴山日报，作为下一次打开程序时仍能查看的历史。

中途关闭、拖拽、暂停、专注、隐藏、切换模式、调整角色人数/人格或退出会立即取消当前场景，不进行提前结算。此期间禁止探险、议会、香蕉竞速或其他短剧抢占角色动作。

每个案件**每章只能结算一次**。重复调用旧章节计划也无法从资源系统再领取奖励；三章结束后展示已结案状态，不能反复刷资源。

## 本地存储的原子性与兼容

城市故事没有新增第二份金钱/剧情文件，而是直接拓展 v0.16 的 `expeditions.json`：

- `city_cases`：四个固定案件的当前章数、谨慎次数、大胆次数和结案结果；
- `city_news`：最多24条已完成章节历史，只有固定事件 ID、选择和结局；
- 原有 `resources`、`buildings`、`missions`、`log` 不变，兼容旧版 v0.15/v0.16 存档；
- 奖励和故事进度**一起在同一 JSON 原子提交**，失败时内存也回滚；
- 损坏状态和伪造未知城市 ID 经过白名单与范围校验，不能自动解锁未建建筑或高级故事。

用户从探险档案显式清空资料后，同时删除城市建筑和这四个案件进度；**不会删除独立的猴际关系文件、议会条例或者可选的猴山纪事文件**。

故事场景不截图、不读取用户文件或键鼠、不产生后台定时任务、不访问网络。这是一套完全虚构、可选择的城市生活系统。

## 可离线体验的网页版

`site/city_life.html` 展示四条城市连载事件，每条三章，每章三幕，手动选择两个角色和慎重/大胆路线，能看到资源与关系改变、章节历史和不同结局。为了方便体验网页默认全部开放，**与必须先建造建筑的真实 Qt 桌宠行为不同**。网页状态只保存在当前标签页内存，刷新清空，不会写用户磁盘、连接 GitHub 或传输桌面数据。

## 文件清单

- `core/city_life.py`：4事件×3章节、双分支、六人格台词、三幕纯逻辑、单次完成门槛；
- `core/expeditions.py`：为已有资源存档新增原子城市故事结算与日报；
- `ui/colony.py`：真实双猴多窗口表演、任务互斥、打断安全、关系变化；
- `ui/city_life_dialog.py`：选角、选事件、选路线、章节预览与历史；
- `ui/tray.py`：主菜单入口与点击已建建筑的故事入口；
- `site/city_life.html`：完全离线的交互网页；
- `tests/test_v017_city_life.py`：纯逻辑、存档回滚、不能反复领奖等测试；
- `tests/test_qt_v017_city_life.py`：可选本地 Qt 离屏测试；
- `tests/test_v017_site.py`：网页无远程依赖与导航测试。
