# ProfMonkey Desktop v0.15 · Windows 真实体验验收清单（尚未执行）

## 核心交互
- [ ] 默认 1 猴时菜单可查看空白日报但不能出任务；设为 2～6 猴后可选队员。
- [ ] 不同队员技能使三种任务出现成功 / 差点成功 / 猴山事故三个结果；UI 预计奖励与程序结算值一致。
- [ ] 三幕中所有选择成员各有独立动作和台词；未选成员继续正常待机，不抢台词。
- [ ] 三幕未完时，拖动、暂停、专注、隐藏、改变角色数量/人格、切换模式或退出，全部取消，不获得奖励、不改变关系、不写入新事件。
- [ ] 3幕结束后，反复尝试提交也最多结算一次；奖励分别影响香蕉、科研和声望；重启保持数值。
- [ ] 已通过 v0.14 三个法令，对应探险加成生效；出发后再更换条例不影响已经开始的任务。
- [ ] 成功派遣且用户事先启用 v0.12 猴山纪事，能够留下一个三章后续案；未启用则不得创建纪事文件。
- [ ] 部分成功或失败也可以写入一条任务日志，但奖励严格遵守各自的数值表；等级/称号不会误加。
- [ ] 资源达到 12、12、12 以及 20/20/20 后自动解锁相应虚构科研成果。
- [ ] 报纸只显示猴山内部信息，可手动另存 TXT；不访问浏览器历史、键盘或桌面图片。

## 隐私与稳定
- [ ] 第一次成功派遣之前，`expeditions.json` 不存在；首次成功后采用安全原子写入。
- [ ] 36条探险记录上限、999资源和个人出勤数上限；非法 JSON 字段不执行任何操作。
- [ ] 面板清空探险档案须确认，并且不改变 `relationships.json`、`monkey_laws.json`、`chronicle.json`。
- [ ] Windows 10/11、100/125/150/200%缩放、多个显示器、透明区域鼠标穿透和2小时长跑测试。
- [ ] 本轮禁止消耗 GitHub Actions 额度；需要验证时仅由开发者手动在本地运行测试。
- [ ] 缺失的 v0.10 六猴像素素材未恢复，不能声称已发布完整图形正式版。
