# P01 · 透明桌面猴子与命中探针

- **依赖**：P00。
- **范围**：单一静态角色、Qt 透明无边框顶层窗体、透明区域 OS 形状穿透、可拖动像素、右键菜单、系统托盘退出、初步 DPI。
- **模块**：`app.py`, `ui/overlay.py`, `ui/tray.py`, `core/alpha_mask.py`, `adapters/screen_info.py`。
- **非目标**：自动移动、动画、物理投掷、热键、全局监听、系统恶作剧。
- **自动测试**：`python -m pytest -q`，检查透明 Alpha 和 hit spans、边界、素材一致性、Qt mask（依赖安装后）。
- **Windows 手工验收**：`docs/P01_windows_manual_checklist.md`，尤其通过透明角落点击下层按钮。
- **执行状态**：原型代码写好，尚无 Windows 真机通过证据。
- **风险**：某些 Qt/Windows 版本的 top-level region 对命中行为不一致；必要时单独添加 Win32 原生区域命中探针，不可使用全局 `WS_EX_TRANSPARENT`。
