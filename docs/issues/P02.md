# P02 · 帧动画和动作管理器（开发分支中的候选实现）

- **依赖 / 门禁**：P01 在 Windows 真机通过后，P02 才允许合并进稳定 main。当前只在 `feature/p02-animation` 开发，**不代表 P01 已验收**。
- **范围**：8 套原画衍生的占位动画；原地待机、眨眼、走路、转身、睡觉、醒来、摔倒、爬起；同一 256×256 画布/统一锚点/左右翻转；动画播放器时间增量、循环、优先级、不可中断标志、缺素材降级；自动预览和菜单手动播放。
- **非目标**：桌面自动巡逻、重力碰撞、投掷物理、真实系统恶作剧、自主决策、香蕉事故（P03～P06）。
- **核心文件**：`core/animation.py`、`ui/overlay.py`、`ui/tray.py`、`assets/monkey/manifest.json`、`assets/monkey/animations/`、`tools/generate_p02_frames.py`。
- **测试**：`python -m pytest -q` 纯逻辑/素材测试；Windows 实机运行时用右键菜单逐个触发动作。
- **门禁完成定义**：真实 Win10/Win11 桌面上连续切换动画无闪烁/黑框/位置跳动；每帧透明区域均可正常穿透；鼠标拖拽、托盘、退出不退化；缺某一个非必需帧会回退原始猴子而非崩溃。
- **目前已验证**：纯 Python 状态机与文件格式；自动生成帧文件在本地解码有效。Qt GUI 和 Windows 点击穿透需要用户 Windows 手工实测。
- **回滚**：切换至 `main` 可回到 P01 代码，动画候选实现只在独立分支。
