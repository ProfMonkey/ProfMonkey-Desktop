# 🐒 ProfMonkey Desktop v0.12 — 猴山纪事（源码候选）

> 基于 v0.11 人格化学反应开发分支。此处没有声称恢复未上传的 v0.10 396 帧像素素材；仍未完成 Windows 真机 GUI / 打包验收。

## 核心升级：每场猴际互动会留下下一集

本地「📖 猴山纪事」**默认关闭**。用户在右键 / 托盘菜单手动开启后，以下**虚构事件正常结束**会种下一条可继续的案件：香蕉争夺战→「消失的香蕉」、猴学委员会→「猴山考试周」、发明×学究/队长→「试飞计划」、困猴×队长/发明→「出勤记录」。

每案固定 **3 章**，每章 2 幕。第 1 章铺垫，第 2 章调查，第 3 章结案；根据双方既有信任和好感，出现「达成合作」或「争议未解」两种结局。用户在猴山纪事面板**主动选择**某一案播放下一章；不会自动抢焦点、自动追更或按现实世界电脑活动触发。

只有角色完成本章最后一幕，才会推进案件进度、写入成长值，且每章最多结算一次。拖拽、隐藏、暂停、专注、关掉纪事或缩减猴子数量均会取消尚未完结的当前章节，且**不改变进度**。

## 新增「成长档案」

每只猴子独立统计研究 / 调皮 / 友善，取最高维度获得称号，并按完整章节累计等级（最高 Lv.10）。这不是对真实用户的分析，也不是 AI 心理画像。

## 本地数据与安全

- 默认**不创建** `chronicle.json`；必须手动开启后、发生受支持的猴山事件才会产生该文件。
- 仅存猴子的整数编号（0–5）、固定事件类型、章数和 3 项有上限的虚构成长值。**不记录**用户输入内容、打开的文件、窗口标题、真实鼠标/键盘、屏幕截图、电脑使用时长或任何联网数据。
- 至多保存 12 个案件和 100 条事件；不自动淘汰尚未完结的案件。
- 右键 / 托盘 → 📖 猴山纪事 → 「清空所有纪事」可以只删本地章节/成长/事件，**不影响**关系、设置和其他档案。关掉开关会暂停记录与访问，不偷偷清空旧档。
- 存档用安全校验与临时文件原子替换写入。

## 可操作的功能

- 菜单开关「📖 记录猴山纪事（默认关）」
- 「📖 猴山纪事 · 连续剧情/成长」：案件选择器、下一章按钮、六猴成长一览、最近记录与明确清空
- 与 v0.11 的双幕导演共用角色播放；人工演示与自动碰面均可成为案件起点（仅在用户手动开启纪事时）。
- 最终章节判定使用 **演出开始时**的关系快照，剧情中不会因其他小事件改口。
