# v0.9 Windows 验收清单

- [ ] 运行 `setup_windows.bat`，启动 `run_windows.bat`，确认角色可见且窗口透明区不遮挡其他软件。
- [ ] 通过右键 / 托盘将数量设为 2；「手动碰面」立即出现两只的不同台词与动作。
- [ ] 切换安静模式，即使开启自动偶遇，也不应自主出现对话。
- [ ] 切换猴山模式 + 开启自动碰面 + 靠近，检查微短剧；两分钟内不会连续刷屏。
- [ ] 拖动猴子、正在联合会议、专注计时、隐藏、全体暂停时不产生自动偶遇。
- [ ] 进入设置关闭自动偶遇，关闭并重新运行，确认持久化；从托盘开关亦应生效。
- [ ] 从 6 只变回 1 只时，不再出现双猴台词；重新增加猴子无残留状态。
- [ ] 125%、150%、200% 缩放下检查拖动、穿透及屏幕边界。
- [ ] 退出后进程和所有道具窗口消失，无驻留后台进程。
