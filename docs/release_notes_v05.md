# v0.5.0-colony-candidate｜猴山人口普查

## 新增：一键选择 1～6 只猴子

- **桌宠菜单按钮**：右键任意一只猴子或托盘 →「🐒 猴子数量：N 只 · 点击调整」→ 点击 1～6 的数字按钮 → 确定。无需重启。
- **设置窗口**：新增数量滑块（数字输入框）。`monkey_count` 随其他设置保存到本地 `settings.json`，再次启动仍然生效；默认 1 只。
- **真实独立实例**：每只猴子有独立 QWidget 透明窗体、动画播放器、行为大脑、位置、物理、剧情和输入交互；不是在一张图上复制 6 个静态小图。
- **专属鼠标交互**：可以单独戳、拖、抛；右键哪只，投喂/语录/短剧等操作就指向哪只。所有猴子共享安静/猴山模式、尺寸、暂停、静音、隐藏、专注计时和退出。
- **轻量策略**：自动小事故仅由第一只猴子主动触发，其余猴子拥有独立自主动作；每只仍可以手动点播小事故。减少多猴同时抢注意力。
- **动态资源管理**：从 6 变 1 会关闭 5 个窗口并停止其计时器；保留下来的猴子位置不会被无故重置。新增的猴子会分布到现有屏幕的底部可用区域。
- **官网可交互预览**：`site/index.html` 新增 ＋ / − 按钮，支持浏览器中实时展示 1～6 只猴子。网页按钮不会连接桌宠除非未来单独设计通讯机制。

## 未实现

- 多猴之间的碰撞、追逐、打架、集体会议等 **交互 AI** 仍未开发；当前每只猴子独立活动，可能在同一区域叠放。
- DPI、多显示器切换、Windows 透明穿透、托盘控制、EXE 打包、长时间多窗口稳定性均需要 Windows 10/11 真机测试。
- 4～6 只会占用更高 CPU/内存，目前不承诺低配机器达到性能目标。

## 验证

- 纯 Python 测试包括数量上下限、坐标范围、持久化、独立随机流等；`tests/test_qt_colony.py` 需要 PySide6 和图形化 Qt 环境。
- 网站 ＋/− 按钮通过 Chromium 本地 DOM 交互测试，最高 6 只、按钮禁用行为正常、无 JavaScript 异常。
- **项目状态：源码候选；非 Windows 正式发行版。**
