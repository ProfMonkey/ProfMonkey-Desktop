# ProfMonkey Desktop v0.9 — 猴山自动偶遇候选版

## 本次新增

- **自主碰面微短剧**：两只猴子接近后，根据学究/皮猴/困猴性格和已有关系，自主触发打招呼、击掌、争论、睡觉或恶作剧。
- **防打扰**：默认关闭；仅用户勾选且切换到猴山模式、至少 2 只可见猴子时运行。两只之间距离不大于约 90 逻辑像素，每对至少 240 秒冷却，整个猴山至少 120 秒冷却。专注、暂停、拖拽、其他短剧、香蕉竞速、离屏或角色忙碌时不触发。
- **一键体验**：右键/托盘 → 🐾 猴山行动与物理互动 → 「🎭 让附近两只猴子互动一次」，手动演示不需要打开自动偶遇。
- **设置持久化**：菜单与设置页均支持控制，重新打开程序保持用户的开关选择。
- **介绍页更新**：添加自动偶遇演示卡片；离线、纯网页模拟，无桌面访问。
- **算法单测**：包含距离/忙碌过滤、冷却、关系决定分支、手动演示、种子复现、多人最近配对。

## 实现与隐私

决策模块 `core/encounters.py` 不依赖 Qt，也不读取操作系统状态。它只使用我们自己的桌宠坐标、性格和本地关系数值；没有全局输入监听、截屏、联网或移动真实鼠标。所有微短剧都在已有角色窗口中完成。
