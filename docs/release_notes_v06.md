# ProfMonkey Desktop — v0.6.0-social-candidate（2026-10-25）

> 这是源代码候选版，不是 Win10/11 真机通过验收的 EXE。以前的 v0.5 多猴独立窗口仍保留。

## 已加入代码的功能

1. **🎛 猴山管理局**：右键任意猴子 / 任务栏托盘 →「🎛 猴山管理局 · 名字与性格」。可选择 1～6 只猴子，分别设置名字（最多 12 字）和性格，保存后即时生效。删减猴子不擦除暂时隐藏的身份配置，后面增加仍可恢复。每只猴子名字和性格在 `%LOCALAPPDATA%\ProfMonkeyDesktop\settings.json` 离线保存。
2. **🧠 三种性格**：学究猴偏向待机/眨眼，皮猴偏向走路/跑步，困猴更偏向睡觉。仅改变随机行为倾向，不伪装为 LLM 自主智能。人物性格通过固定随机种子可复测。
3. **🗳 猴学委员会**：两只以上同步进入一段有对话、有动作、有结局的联合短剧：1+1=猴→追问证据→证据被吃掉→散会。
4. **🍌 香蕉争夺战**：两只以上加入另一段联合短剧。联合短剧会把成员聚到桌面可用范围内，分别播放动作和名字气泡，结束后回归各自的日常行为。**不是**真实猴子身体之间的物理碰撞或 AI 社交。用户拖拽任意猴子、暂停、专注、退出时可以取消；不会操作其他应用窗口、真实鼠标或文件。
5. **🔕 可选自动联合短剧**：在猴山模式且至少 2 只时，用户**主动开启**后，约 4～7 分钟才有机会出现一段联合短剧；默认关闭。安静模式没有自动社交；专注时不触发。所有成员共用一个联合事件控制器，不能叠加多场联合事故。
6. **📸 一键生成猴山合照**：托盘/右键菜单 →「📸 猴山合照 · 导出 PNG」。生成 1000×660 深色金边合照，含自定义名字、性格和不同姿态。**只合成软件自身 PNG 资源，不调用系统截图 API，也不读取桌面**。
7. **🌐 产品官网升级**：`site/index.html` 添加联合短剧模拟器、猴山合照预览与最新功能卡。网页仅演示静态图片与本地 JavaScript，网页按钮不能控制运行中的桌宠。

## 需要用户在 Windows 上测试的点

- 启动 1→2→6→1，只数正确、每只仍可单独拖动、菜单和托盘可退出。
- 猴山管理局设置 3 只，编辑各自名字/性格，保存、关闭程序、重新启动：名字/性格不丢失。
- 正常显示时，2 只以上打开「猴学委员会」，各自出现对应动作和台词；短剧结束后能自主走路。开会中按全体暂停/恢复、拖动其中一只、减少只数，不能卡住状态机或留残影。
- 打开专注后尝试手动联合短剧，应被拒绝；开启自动联合短剧后，只有猴山模式能低频触发。
- 导出 1～6 只 PNG，确认不包含屏幕上的窗口、密码、消息或私人内容。
- **尤其检查**透明区真实点击穿透、托盘异常退出、125/150/200% DPI、多屏切换和 2 小时 CPU/内存；当前测试环境无法替代 Windows。
