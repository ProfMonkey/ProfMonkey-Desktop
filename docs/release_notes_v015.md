## 这次具体实现了什么

在已有 v0.11 双猴短剧、v0.12 连续剧情、v0.13 议会和 v0.14 法令系统上，加入真正参与猴山世界发展的派遣玩法。

右键猴子或系统托盘 → **「🧭 猴山探险局 · 小队与日报」**。

用户选择 **2～6 只**独立猴子参与以下原创任务：

| 任务 | 擅长的猴子 | 主要收获 |
|---|---|---|
| 🍌 香蕉侦察队 | 皮猴、发明猴、社恐猴 | 香蕉 |
| 🔭 陨石研究所 | 学究猴、发明猴 | 科研点 |
| 🏡 猴山营造队 | 队长猴、社恐猴 | 声望 |

每个角色都有自己独立的任务技能数值；已有猴际好友会产生合作加成，竞争激烈会降低配合程度。**选择不同猴子会真正改变最终成功率与奖励**；计算完全确定性，没有伪随机抽奖。

现行猴山法令在**启程当刻**被固定为本次任务的政策快照：香蕉共享→侦察队加成；火箭许可→陨石研究加成；安静公约→村庄建设加成。就算表演过程中更换法令，也不会偷偷重算已启动的任务。

## 真正的 3 幕队伍动画

所有小队成员（不仅前两只）都参与：

1. 集结、分配任务、检查装备；
2. 探索、调查，按照人格特点独立发言；
3. 根据小队分数演出「大功告成 / 差点成功 / 猴山事故」三类结局。

**只在第三幕完整播放后**结算个人任务经历、资源与猴际关系。中途拖拽、隐藏、暂停、专注、改角色人数、改性格、退出或切换静音模式都会取消这次任务，**不奖励任何资源、不更新关系**。任务与议会、双猴短剧、群演、香蕉竞速互斥，避免多个事件抢占猴子的动作。

成功远征可衔接现成的 v0.12 三章后续案件：香蕉侦察→香蕉调查，陨石研究→火箭事故，村庄建设→猴山考试周；只有用户另外显式开启猴山纪事时才会创建后续案件。

## 香蕉、科研点、声望与实验成果

新增独立虚构资源：**🍌香蕉 / 🔬科研 / ⭐声望**，各 0～999，只有游戏意义，不涉及真钱、投资或任何系统性能。

达到条件就自动显示无消耗的收藏成果：

- 🍌 香蕉研究仓库：香蕉≥12；
- 🔭 银河猴山望远镜：科研≥12；
- 🏛️ 猴山公共广场：声望≥12；
- 🌌 银河猴山联合实验室：三项都≥20。

## 多猴关系结算的额外优化

把成功任务的团队好感更新改成了**一次完整的本地批量写入**：6只猴子最多涉及15对关系，以前调用公共会议写法会执行最多15次原子文件写入，现在整队任务只写一次。新增拒绝重复编号、无效猴子编号和虚假任务结果的回归用例。

## 🗞️ 猴山日报与可选分享

日报读取**猴山内部模拟数据**：资源、最近5次派遣标题、猴子任务经验榜、已生效法令和已解锁科研成果。

用户可以主动使用 **「💾 导出日报 TXT」** 选择文件路径并保存文字；不自动导出、不截图、不读取用户电脑真实活动或网络记录。

## 离线存储与删除

`ExpeditionJournal` 单独保存到用户配置目录里的 `expeditions.json`；第一次正常完成任务前不创建此文件。仅保存固定任务ID、2～6个角色编号、完成结局、虚构资源与计数，最多 **36 条事件**。采用白名单加载、容量上限和原子写回，可从面板明确确认后独立清空，不删除猴际关系、法令和选择性纪事。

网页 `site/expeditions.html` 是完全离线的交互式预览，只有页面内存，没有用户账号、遥测或同桌宠存档的网络同步。刷新网页会重置演示数据。

## 源码位置

- `core/expeditions.py`：评分、角色技能、政策加成、三幕有限状态机、记录、科研解锁、日报文本；
- `ui/colony.py`：多窗口独立动作、互斥、打断与完成结算、成功后可选续集；
- `ui/expedition_dialog.py`：队员选择、预计成果、任务启动/取消、日报、清除与导出；
- `ui/tray.py`：菜单入口及本地存档实例；
- `site/expeditions.html`：网页离线演示。

### 不使用 GitHub Actions 的本地验证方法

可在已经安装开发依赖的电脑上手动执行：

```bash
python -m pytest -q tests/test_v015_expeditions.py tests/test_v015_site.py
```

需要 Windows 和图像素材才能执行的 Qt 联调：

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
python -m pytest -q tests/test_qt_v015_expeditions.py
```
