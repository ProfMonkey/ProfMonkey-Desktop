# ProfMonkey Desktop v0.0.2-p02 · 动画候选实现（2026-10-25）

## 本次新增

- 独立于 UI 的 `AnimationPlayer`，支持指定帧率、逐帧时间推进、循环/结束转换、优先级、不可中断、暂停与镜像方向。
- 8 套动画 / 44 帧 PNG：待机、眨眼、原地走路、转身、睡觉、醒来、摔倒、爬起，全部基于自制 P01 SVG 衍生。
- 透明窗体按照当前显示帧更新非矩形区域遮罩，边缘交互命中随画面变化，拖动时停止换帧。
- 托盘与右键菜单新增手动播放、循环预览、暂停/恢复。
- 轻量开发工具生成可复现素材，附静态总览图和屏幕外独立合成的动画 GIF。
- 纯 Python 动画测试与 Qt 可用时 GUI 冒烟测试。
