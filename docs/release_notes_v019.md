# 🏛️ ProfMonkey Desktop v0.19 · 猴山自主社会（独立源码开发分支）

**本版本不是 Windows 正式发行版。** 本轮仅提交到 `feature/v019-autonomous-monkey-society`，从 v0.18 专用分支继承；不创建 PR、不合并 main、不运行 GitHub Actions。所有提交带 `[skip ci]`，不生成 Windows EXE。

## 现在历史会影响真实的猴子行动

从 v0.17 案件、v0.18 历史结果以及现有议会法令和猴际关系计算五个展示与行动要素：

1. **文明气候：** 合作、创新、分歧三个 0–100 的虚构指数，固定公式，不是大语言模型推断，更不是现实用户性格画像。
2. **城市岗位：** 每只猴子在目前**已建成的建筑**中，根据原有性格获得首选职位。没有建筑的猴子会变成自由探险者。
3. **意见阵营：** 根据猴子性格、城市已保存的合作/突破历史、旧案结局及猴际信任和竞争，成为共治派、开拓派或独行派。可随历史自然变化，人物并非永久被贴标签。
4. **行为偏好：** 仓管员更倾向散步巡视，星际观测员更常观察，广场策划师更爱活动，实验室研究员更倾向思考；通过 `Brain.set_civic_bias()` 将非负权重加到已有 idle/walk/blink/sleep/turn/run 动作上。没有引入虚构的未绘制动画。
5. **真实双猴互动：** 原有 `EncounterDirector` 在自主社会开启时能根据建筑岗位、阵营和历史计算新的有限双幕事件：合作值班、广场筹备、科研复核或意见冲突。互动正常演完后仍走原版好感/信任/竞争存储逻辑。被打断不结算。

由此，已有的**香蕉共享条例、安静公约、火箭许可**有了额外可见的社会反馈；城市合作程度还会微调原有自动多人短剧「开会 vs 香蕉争夺战」的概率。前提是用户此前已单独选择允许自动多人短剧。

## 与普通宠物独立的许可、暂停和安全规则

- `Settings.civic_autonomy` **默认 false**，旧存档未开启时没有新行为。
- 用户从**托盘 → 🏛️ 猴山自主社会 · 岗位/阵营/互动**，或者原有「猴山行动与物理互动」菜单中显式开启。
- 只有**猴山模式**才启用动画权重与历史主题偶遇；安静模式不会变化。
- 自动碰面仍需另行允许已有 `ambient_encounters`（默认关闭）。仅开启 v0.19 不会自动替用户打开自动碰面。
- 如果通过了「猴山安静公约」，自动偶遇和自动多人短剧照旧被禁止；专注、暂停、隐藏、被拖动、正在演出其它情节等情况沿用既有拒绝与互斥逻辑。
- 角色动作只在当前已有的社交计时器上**每20秒刷新一次**，没有额外线程、后台进程、联网或文件监听。
- 单纯打开社会面板不会写存档，也不触发情节；内容来自本地虚构游戏资料。
- 关闭自主社会会立刻把 **所有猴子的 civic action weights 恢复为全零**，下一次动作由旧行为模型决定。旧版本动画、六种人格、低频冷却和历史记录均不删除。
- 没有因自动运行而授予香蕉、科研、声望；只有用户原本明确完成的剧情/探险才能领取对应资源。

## 原有存档仍然是唯一事实源

不新建 `society.json`：只读取现有 `expeditions.json`（建筑、四大城市案件、后续历史）、`monkey_laws.json`、`relationships.json`、设置里的6个本地猴子名字和性格。社会岗位、城市气候与阵营均为**派生快照**，修改旧历史或清空旧档案后立即可以重新推导。关系仍由先前 `RelationshipStore` 的完成事件规则写入，不引入独立交易。

## 原生桌面与浏览器入口

Qt 界面：`ui/society_dialog.py` 提供六猴角色岗位、阵营、文明快照、是否启用自主社会/低频偶遇的两个分离开关，还可手动指定两只不同的猴子演出一次历史主题偶遇（需要有空闲的可见角色）。

网页：`site/civic_society.html` 是不依赖任何外部库的独立互动沙盒。访客可配置四座建筑、五项假想历史选择、三条法令、当前猴子数量，查看城市合作/创新/分歧、人物职位与阵营，手动安排猴际互动并观察演示用关系和日报变化。网页**与真实桌宠存档完全隔离**，不会保留到下次打开。

没有替换 v0.13 旧 `site/society.html`，旧议会网页依然保留。

## 测试与验收现状

新增：

- `tests/test_v019_civic_society.py`：派生岗位、历史气候、阵营、脑行为权重开关、实际偶遇、无资源写入、旧版兼容。
- `tests/test_qt_v019_society.py`：可选本地 Qt 离屏对话框、开关独立性、未启动不改资源。
- `tests/test_v019_site.py`：站点离线资源、导航链路、保留旧版议会页。

此外，本轮对浏览器内嵌脚本进行了本地语法校验及模拟交互：**网页脚本可解析；历史变化、关系结算与重置逻辑执行成功**。这不是 Windows 真机验收，也不代表上述完整 Python/Qt pytest 已实际执行。

开发者可以在本机手动执行（没有 GitHub Actions）：

```bash
python -m pytest -q tests/test_v019_civic_society.py tests/test_v019_site.py \
  tests/test_v018_city_evolution.py tests/test_v017_city_life.py
```

若已安装 PySide6，再以本地 offscreen 环境检查 `tests/test_qt_v019_society.py`。最后需要 Windows 10/11 的多显示器、气泡遮挡、专注中断、透明窗口点击区域与持续运行验收。

**尚未实现：** 独立路径规划、复杂 AI 代理、建筑内可见工作动画、真正的城市地图同步。v0.10 六猴独立像素动画素材尚未恢复。现在“自主”特指本地角色行为概率和有限社会偶遇受到历史影响，不是无限制生成 AI NPC。
