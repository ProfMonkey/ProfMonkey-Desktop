# ProfMonkey Desktop v0.8 — 猴山生活系统候选版

> 状态：源码候选版。当前开发环境没有 PySide6，GUI、Windows 透明窗口和家具窗口仍需在 Windows 真机验收。

## 新增

- **猴山关系档案**：本地保存猴子之间的好感、竞争、信任和互动次数；会议增进关系，碰撞和香蕉争夺提高竞争；支持手动和解和师徒关系。
- **可拖动家具与道具**：香蕉树、猴学黑板、蹦床、教授椅、猴山镜子。左键互动、拖动摆放、右键收起；最多同时摆放 8 件。
- **每日猴山任务**：每天轮换 3 项任务；完成当日全部任务奖励 3 点猴学积分。任务进度和积分仅存本机，不观察键盘、应用或用户学习状态。
- **猴山故事卡 PNG**：可从 7 个故事主题中选择，生成 1200×800 PNG；仅使用本项目角色素材、名字和文案，不截取桌面。
- **产品介绍页更新**：新增关系系统、家具、每日任务和故事卡的网页演示。网页演示不会操控桌宠。

## 交互入口

- 右键猴子 / 托盘 →「猴山关系档案 · 好友/死对头/师徒」
- 右键猴子 / 托盘 →「今日猴山任务 · 猴学积分」
- 右键猴子 / 托盘 →「猴山家具与道具」
- 右键猴子 / 托盘 →「导出猴山故事卡 PNG」

## 本地数据

- `relationships.json`：猴子之间的关系数值和师徒配置。
- `daily_quests.json`：日期、任务进度、猴学积分和完成天数。
- 两类数据均保存在应用配置目录，不上传网络。

## 已知限制

- 家具目前是独立悬浮窗口，点击触发互动；还没有自动检测猴子走近家具的完整环境感知。
- 关系值由预设规则更新，不是生成式 AI，也不会自主编写剧情。
- 每日任务由用户主动触发的菜单动作计数；不会监控实际键盘输入或应用使用情况。
- Windows 透明穿透、家具窗口层级、多屏/DPI、安装包与长时间运行必须在真实 Windows 环境验收。
